Dirty Block Capture

The question that decides whether Repo as Root Disk is buildable at all: can the set of blocks a guest has written be captured out of a browser VM, and can replaying that set onto a blank disk reproduce the machine's state exactly? No network, no git host, no sync protocol. Just the storage layer.

The invariant under test: blank disk + captured writes === live disk, byte for byte. If that holds, the dirty set is reachable and lossless, and every phase of the sync protocol has something real to operate on. If it does not, the design needs rethinking before anything else is built.
