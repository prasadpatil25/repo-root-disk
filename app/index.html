Repo as Root Disk

A Linux machine running in this tab, whose disk is stored as ordinary git objects in your own repository. Sync commits the blocks the guest has written; restore rebuilds the machine from a commit alone. Nothing runs on a server.

Use a throwaway repository. This writes real git objects and spends your account's write budget. Compaction rewrites the branch and discards its history.

Repository

A fine-grained token scoped to one repository with contents read and write. It is held in memory only. Only GitHub supports the parentless commit that compaction needs.

Not connected.

Machine

The base image streams over HTTP and is never written to. Only the blocks the guest changes are committed.

Guest

Linux from a CD-ROM, with the disk as the primary master. The guest root is read only, so the mountpoint is gone on every boot and the disk has to be mounted again. This mounts a block device, not the repository: writes reach the repository at the next sync, not before.


  
Click the terminal and type. Keystrokes go straight
  to the guest, so history, tab completion, Ctrl+C and multi-line
  constructs all work because the shell is doing them, not this page.

    The CD guest is Buildroot with uClibc and cannot use a package manager:
    nothing in any repository is built against that libc. So a real distribution
    goes on the disk instead. Alpine is musl based and ships
    apk, and a chroot into it is a real Alpine userland whose every
    write lands on the disk and syncs to the repository. The rootfs comes from
    this page's own origin through the emulator's 9p share, so no server and no
    network are involved.
  


  

    

      
      
    

    
  

  

    Pick every package and its dependencies together. Offline, apk
    resolves only the set it is handed, so a package selected on its own fails
    when something it needs is missing. Installing offline also means nothing is
    checked against a signed index, which is a real reduction in assurance.
    vim and its four dependencies are in
    vendor/alpine/packages.
