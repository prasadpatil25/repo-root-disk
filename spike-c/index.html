The Full Loop

A guest writes, the dirty set is captured, chunked and committed into a real repository, and a machine is rebuilt from that commit alone. Syncing repeatedly measures what an incremental commit actually costs, which is the experiment the chunk-exploded design has been asserting without evidence.

Two invariants: a machine rebuilt from a commit reads back what the original wrote, and commit N uploads only the chunks whose content changed while still referencing every chunk the disk needs.
